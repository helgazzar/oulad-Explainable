# Machine Learning for Educational Data Analytics: Building Capacity for Data-Informed Student Success

Interpretable machine learning models for analyzing student engagement 
and predicting student success using the Open University Learning 
Analytics Dataset (OULAD). This project develops transparent, explainable 
ML models (Random Forest, XGBoost, Logistic Regression) with SHAP-based 
interpretability and fairness evaluation across demographic groups.

## Repository Structure

- `data/` — OULAD data files (not committed; see download instructions below)
- `notebooks/` — Jupyter notebooks for exploratory analysis and experiments
- `src/` — Python source code for preprocessing, feature engineering, and models
- `docs/` — Project documentation and workflow guides
- `results/` — Figures, tables, and model outputs

## Dataset

This project uses the Open University Learning Analytics Dataset (OULAD): 
32,593 students, 22 courses, 10.6M+ interaction records. Download the 
dataset from the official OULAD site and place the CSV files in the 
`data/` folder.

Kuzilek, J., Hlosta, M., & Zdrahal, Z. (2017). Open University Learning 
Analytics dataset. *Scientific Data*, 4, 170171.
